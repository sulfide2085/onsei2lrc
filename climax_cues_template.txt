# climax_finder 线索规则模板
#
# 用法：python climax_finder.py "音频目录" --cues 本文件
#
# 格式：4 行正则，顺序固定，空行与 # 开头的行会被忽略
#   第 1 行  射精拟声      +2 分
#   第 2 行  已然/进行     +2 分（明确说「出来了」）
#   第 3 行  倒计时        +1 分（部分作品用来预告高潮）
#   第 4 行  负面          -3 分（未然/祈使/回顾/泛指——有线索但不是高潮）
#
# ---------------------------------------------------------------------------
# 默认规则（针对 RJ324692 总结，换个作品大概率需要改）
# ---------------------------------------------------------------------------
ぴゅ|ピュ|どぴゅ|ドピュ|びゅ|ビュ|びゅく|びゅる|ぴちゅ
出(た|てる|ちゃ|てしま)|イッ?(た|ちゃ)|射精(し)?(た|てる)
[5５][…\s、.]*[4４][…\s、.]*[3３]|[3３][…\s、.]*[2２][…\s、.]*[1１]|ぜー?ろ
(し|に)?そう|ないように|寸前|したい|したから|出して(ください|ぇぇ)|ばかり

# ---------------------------------------------------------------------------
# 怎么调
# ---------------------------------------------------------------------------
# 1) 先不加 --cues 跑一遍，看输出的「转写」行
# 2) 找出被误报的那几句，把它们特有的词加进第 4 行（负面）
# 3) 找出漏掉的高潮点附近说了什么，把词加进第 1/2 行
# 4) 注意：负面权重是 -3，比正面 +2 更强，用得准比用得多重要
#
# 常见的「假阳性」句型，可考虑加进负面行：
#   〜しそう / 〜そう         快要（还没发生）
#   〜して / 〜してください    祈使、请求
#   〜したい / 〜欲しい        愿望
#   さっき〜した / 〜したから   回顾（已经发生过了）
#   〜するのは / 〜って         泛指、描述
