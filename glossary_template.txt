# 术语表模板
#
# 用途：让同一术语在全篇译法一致（避免同一个词一会儿这么译、一会儿那么译）。
# 用法：复制成 glossary_common.txt 或你自己的名字，然后：
#         python onsei2lrc.py "音频目录" --glossary glossary_common.txt ...
#       WebUI 里直接粘贴到「术语表」文本框也行。
#
# 格式：一行一条
#         日文->中文
#         日文->中文 #备注（备注会一起发给模型，用来说明为什么这么译）
#
#       行首 # 为注释行，空行忽略。
#       分隔符是 ASCII 的 -> （半角减号 + 大于号），前后不要加空格。
#
# ---------------------------------------------------------------------------
# 收录标准
# ---------------------------------------------------------------------------
# ✅ 该收：跨作品通用的术语、题材词、称呼类通用词
# ❌ 别收：具体角色名（每个作品都不同，固化进来只会在下个作品里帮倒忙；
#          模型通常能自行音译，且同一作品内本来就一致）
#          真需要时临时追加几条、用完删掉即可。
#
# 注意：术语表**随每次请求一起发送**，条目别太多（几十条以内），
#       否则拖慢速度、还可能挤占上下文。
#
# ---------------------------------------------------------------------------
# 示例（把下面几行取消注释即可试用；请按自己的素材调整）
# ---------------------------------------------------------------------------
# 先輩->前辈 #称呼
# お姉さん->姐姐 #称呼
# 魔法少女->魔法少女 #题材词，保留汉字
