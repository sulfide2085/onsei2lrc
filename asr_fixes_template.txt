# ASR 修正表（模板）
#
# 格式：听错的=>正确的       行首 # 为注释，行尾可加 " # 备注"
# 时机：转写之后、翻译之前，直接替换日文原文
#
# 为什么需要这张表：
#   ASR 听错的字已经写进日文原文里了，翻译环节救不了它
#   （术语表是「日文->中文」，管的是译文用词，管不了原文的错字）
#
# 怎么用：
#   ① 跑一遍时加 --keep-ja，拿到 *.ja.lrc
#   ② 对着音频读一遍日文原文，把听错的记到下面
#   ③ 带 --fix-asr 重跑：--retranslate --reuse-translation --fix-asr 本文件
#      只有被改动的行会重译，几秒钟完成
#
# 注意：错字是**随机的**，没有跨作品通用的条目，所以这里默认是空的。
#       每换一个作品重新校对一次即可，条目通常只有几条。
#       原始转写会留档在缓存的 ja_raw 字段，改错了随时能回查。
#
# 示例（都是编造的，仅示范格式，别照抄）：
# トラック=>トラック #编号写错类
# 序章=>序章 #同音异字类
# 抵抗する記録=>抵抗する気力 #词尾听错类
